## M01–M17 implementation, acceptance and activation

These are three independent states. **Built** means owner code is present in this checkout of main, not that every milestone phase is complete. **Verified** requires the complete required acceptance, not a merge, an integrity-validator pass or a focused fixture pass. No milestone below has evidence establishing that complete acceptance; linked receipts retain their narrower passes and failures. **Turned on** records the shipped default, not an operator's possible environment override. All additive v6 features are off for the 0.6.5 PM default; existing conversation, task-note, trusted plug-in and split-layout behavior is not evidence of v6 activation.

Flag sources: [capability-flags.ts](../packages/core/capability-flags.ts) constructs every registered key as false; [host-flags.ts](../packages/core/host-flags.ts) declares the separate M03/M06/M07 keys false and enables them only for explicit host environment values. M12's specified keys are absent from both registries and its owner implementation/evidence is absent from this main checkout. M01 has no product activation flag.

## Generated-app boundary

`GENERATED_APPS_ENABLED` is true in current source; the earlier disabled checkpoint descriptions in [the historical ledger](archive/progress-history.md) are historical. Generated apps are preview (PM default pending owner confirmation). The controller fetches the fixed IIFE without credentials or redirects, then the receiver creates an opaque data worker inheriting its CSP. The fetched asset's HTTP CSP is defense in depth. Host-owned packages/widgets/theme.ts base classes and tokens are discoverable. No generated host JavaScript or hard memory quota is claimed; trusted PDF workers are a separate path.

ChatGPT subscription login succeeded and the user selected GPT-6.1 Sol. Credentials remain in application-owned Pi storage and are never printed. No API billing fallback is enabled.

Development uses Vite 5173, host 4317 and widget origin localhost:4318. Restart the owned host after core changes; the frontend is watched. Transient development session IDs are not part of this contract.
