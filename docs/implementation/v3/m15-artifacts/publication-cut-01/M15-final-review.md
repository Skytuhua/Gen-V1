## Boundaries rechecked without an additional defect

The host remains the only Store writer. Source I/O occurs before synchronous Store callbacks, and the final commit and runtime boundaries recheck ownership and retained source authority. The new routes remain beneath the existing host, origin, session, and CSRF protections. They do not introduce a second send queue, native history replacement, tool grant, or approval path.

Message admission coalesces matching in-flight commands and checks durable receipts before treating a rejection as definitively unaccepted. Accepted-input recovery compares the complete saved input inside the Store transaction and permits cancellation only for a persisted input with no run assignment and no recorded runtime entry. Runtime ambiguity remains fenced. Keeping captured sources requires ordinary explicit Resume. The client persists the exact recovery command before transport, retries its original identity after uncertain acknowledgment, and retains a reachable retry when cancellation has removed the input from the list.

Source drafts stay separate from the canonical text journal while sharing generation checks. Pending sends freeze source identity, owner, delivery mode, and command ID. Late acknowledgments cannot clear a newer source generation. Named saves preserve typed source metadata, and text-only restoration is explicit. Source-bearing transfer uses format version 2 and commits the prompt and its companion records atomically. The host still validates imported references before any source-aware send.

Long activity output retains canonical messages, bounds mounted rows, and uses the authenticated host read for complete search and copy. Host and client row identities agree. The read rejects an incorrect owner, activity ID, revision, or incomplete result. Presentation anchors remain local view state. The production App anchor navigation/reload, lost-cancellation-receipt recovery, and exact canonical-message fallback cases are represented in `app-browser-final-03`, which recorded 19 passing cases and exit 0. This review opened the actual receipt and log and did not treat a suspected hidden-details anchor problem as an observed defect.

Evidence grades exclude foreign-account observations. Current freshness is checked against the declared source cut. R1's completeness guard now prevents a bounded presentation from being mistaken for a complete verification history. Historical source opening returns retained captured bytes. Historical log and screenshot navigation remains explicitly unsupported.
